# 万界系统管理局（System Flow）0.1.5

面向 SillyTavern 1.19.x 的独立 UI 扩展。系统选择与系统管理是两个独立页面，并提供按系统隔离的任务、角色资料、积分、商城、背包和日志。

## 安装

1. 确保 GitHub 仓库是公开仓库，并在仓库根目录包含 `manifest.json`。
2. 在 SillyTavern 的「扩展」面板粘贴仓库 URL 安装。
3. 安装完成后刷新或重启 SillyTavern，确认「扩展」列表中出现「万界系统管理局（System Flow）」。
4. 刷新或重启后可通过以下任意入口打开同一个系统管理局界面：
   - 输入框左侧魔法棒菜单中的「万界系统管理局」。
   - 聊天界面右下角的画笔悬浮按钮；再次点击可关闭。
   - 酒馆右侧「扩展」抽屉内的「万界系统管理局」设置项。

也可将整个仓库目录手动放入 `data/<用户目录>/extensions/`。`manifest.json`、`index.js` 和 `style.css` 必须直接位于该仓库目录根部，不能再套一层同名目录。

如果安装时提示目录已存在，但扩展列表没有名称，说明 `data/<用户目录>/extensions/<仓库名>/` 是残留目录。先备份其中的自定义文件，再删除该残留目录后重新安装；不要清理聊天数据、IndexedDB 或浏览器存储。

## 功能

- 打开插件后首先进入独立系统选择页；确认后才进入系统管理页。
- 支持单选、多选、随机抽取一个或两个系统，以及自定义系统。
- 管理页显示当前系统，并可随时返回选择页；原选择和存档不会被清空。
- 多系统组合时可切换当前管理目标，每个系统使用独立的 `systemData[systemId]` 数据分区。
- 自定义系统名称、规则描述和商城开关。
- 简单/正常/地狱级商城价格倍率。
- 每个聊天、每个系统分别保存积分、属性点、角色资料、任务、商城商品、背包和日志。
- 任务进度、完成奖励、属性点加点、商城购买和积分扣除。
- 将当前系统状态注入 AI 上下文；识别 `<SF_ACTION>...</SF_ACTION>` 提议，并在用户确认后执行。
- 魔法棒菜单、悬浮画笔和扩展设置抽屉三个入口，共用同一个独立管理界面。
- 从 SillyTavern 1.19.x `getCharacterCardFields()` 读取当前 AI 角色卡，并单独读取 `name1` 与 `powerUserSettings.persona_description` 作为当前用户 Persona。
- AI 角色卡、用户 Persona 和插件内部角色资料分开显示；首次自动导入只填补插件内部资料的空字段，手动保存后不再覆盖。
- 身体、智力和属性名称使用中文映射，内部英文 key 保持不变。
- 针对 320px、375px、390px、430px 手机宽度增加独立布局、全屏可滚动弹窗、安全区域和触控尺寸适配。

## AI 操作提议格式

```xml
<SF_ACTION>
{"type":"task_create","title":"找到旅店","description":"在天黑前找到落脚处","reward":{"currency":30,"attributePoints":1}}
</SF_ACTION>
```

支持 `task_create`、`task_progress`、`task_complete`、`event_notice`、`unlock_shop`。每次最多一个操作提议，必须在面板中确认。任务完成操作要求进度达到 100%。

多系统组合时，AI 操作应附带目标系统 ID：

```xml
<SF_ACTION>
{"type":"task_create","systemId":"roleplay","title":"调查遗迹","reward":{"currency":30,"attributePoints":1}}
</SF_ACTION>
```

## 0.1.5 更新

- 将插件拆分为独立的系统选择页和系统管理页，不再把选择内容与管理功能混在同一页面。
- 系统选择页显示全部系统卡片、简介、功能范围、选中效果、单选/多选和随机选择。
- 确认选择后才写入当前聊天；返回选择页保留之前的选择和全部数据。
- 新增 `systemData` 按系统隔离存档。旧版根级任务、积分、资料、背包、商城和日志只迁移给首个选择的系统，不复制到其他系统。
- `META_KEY`、原根级字段和 `version: 1` 保持兼容，旧存档不会被清空或重置。
- 管理页根据系统 `features` 动态显示角色资料、任务、商城、背包和日志页面。
- 多系统组合提供系统切换器，AI 操作可携带 `systemId` 定向到对应系统。
- 接入 1.19.x 角色卡与 Persona API，并严格区分 AI 角色卡、用户 Persona、插件内部资料。
- 插件内部资料首次只导入角色卡的非空空白字段；用户手动保存后自动读取不会覆盖。
- 所有属性显示名称中文化，旧英文 key 继续用于存档。
- 重做手机端选择卡片、表单、统计区、标签页和全屏弹窗滚动布局。
- 已通过隔离 DOM 测试；真实 SillyTavern 1.19.x 桌面端和手机端实机验证仍需用户环境确认。

## 注意事项

- 这是可运行原型，不是正式稳定版；请先在测试聊天中验证。
- 切换聊天时，插件会读取该聊天自己的元数据存档。请勿手动复制不同聊天的 `system_flow_v1` 元数据。
- 删除聊天或清理聊天元数据可能导致对应存档丢失，重要进度请定期备份聊天。
- 商品效果、BUFF 持续时间、库存系统、套装、跨系统联动、完整回滚和导入导出尚未实现。
- 若入口未出现，请先打开酒馆右侧「扩展」抽屉，在「万界系统管理局」设置项中查看入口状态和最近错误。
- 若三个入口均未出现，请提供 SillyTavern 版本、浏览器控制台中以 `[System Flow]` 开头的日志，以及 Network 中 `manifest.json`、`index.js`、`style.css` 的请求状态。
