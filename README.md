# 万界系统管理局（System Flow）0.1.0

一个面向 SillyTavern 的独立 UI 扩展原型。数据按聊天保存，包含系统选择、自定义系统、任务、属性、积分、商城商品、背包和 AI 操作提议确认。

## 安装

1. 解压 `system-flow` 文件夹。
2. 将整个文件夹放入 SillyTavern 安装目录的 `data/<用户目录>/extensions/` 下（多数单用户安装通常是 `data/default-user/extensions/`）。
3. 重启 SillyTavern，进入「扩展」面板启用 System Flow。
4. 打开一个聊天记录，在扩展设置中展开「万界系统管理局」。

也可以将本项目放入自己的 Git 仓库，再通过 SillyTavern「扩展 → 安装扩展」使用仓库地址安装。

## 当前原型包含

- 预置系统选择、多系统同时启用、随机抽取。
- 自定义系统名称、规则描述及是否拥有商城。
- 简单/正常/地狱级商城价格倍率。
- 聊天级数据：积分、属性点、个人资料、任务、商城物品、背包、日志。
- 任务进度、完成奖励、属性点扣除与加点、商城购买和积分扣除。
- 将当前系统状态注入 AI 上下文；识别 `<SF_ACTION>...</SF_ACTION>` AI 操作提议，并要求用户确认后执行。
- CHAT_CHANGED 时重新读取当前聊天的 metadata，避免跨聊天串档。

## AI 操作提议格式

```xml
<SF_ACTION>
{"type":"task_create","title":"找到旅店","description":"在天黑前找到落脚处","reward":{"currency":30,"attributePoints":1}}
</SF_ACTION>
```

支持 `task_create`、`task_progress`、`task_complete`、`event_notice`、`unlock_shop`。AI 提议需要在插件面板确认。任务完成操作要求进度达到 100%。

## 重要限制（0.1.0 原型）

- 这是可运行原型，不是已完成的正式发行版；请先在测试聊天中验证。
- SillyTavern 的扩展事件数据结构、`setExtensionPrompt` 和聊天消息事件可能随版本变化。当前按公开 UI Extension API 编写，未在你的本机 1.18 环境实机验证。
- AI 操作提议的消息事件解析存在版本差异；如果没有自动识别，可将 AI 的 JSON 操作块复制给开发者用于适配，勿直接手动改聊天数据。
- 商品效果、BUFF持续时间、套装、商城库存、抽奖/概率、跨系统联动、完整回滚和导入导出尚未实现。
- 为避免不安全的现实操作，本原型不提供现实武器获取或使用内容；幻想题材中的装备系统可后续以非现实化道具/防护装备扩展。
- 数据写入当前聊天 `chatMetadata.system_flow_v1`。删除聊天或清理聊天元数据可能导致该聊天存档丢失，重要进度请定期备份聊天。
