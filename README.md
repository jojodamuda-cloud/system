# 万界系统管理局（System Flow）0.1.1

面向 SillyTavern 的独立 UI 扩展原型。界面采用蓝色赛博控制台风格；数据按聊天独立保存，包含多系统选择、自定义系统、任务、角色属性、积分、商城、背包和 AI 操作提议确认。

## 安装

1. 下载并解压本项目。
2. 将 system-flow 文件夹放入 SillyTavern 的 data/<用户目录>/extensions/ 目录。
3. 重启 SillyTavern，在「扩展」面板启用 System Flow。
4. 打开聊天，在扩展设置中展开「万界系统管理局」。

## 功能

- 预置系统选择、同时运行多个系统、随机抽取一个或两个系统。
- 自定义系统名称、规则描述和商城开关。
- 简单/正常/地狱级商城价格倍率。
- 每个聊天独立保存积分、属性点、角色资料、任务、商城商品、背包和日志。
- 任务进度、完成奖励、属性点加点、商城购买和积分扣除。
- 将当前系统状态注入 AI 上下文；识别 <SF_ACTION>...</SF_ACTION> 提议，并在用户确认后执行。
- 蓝色赛博界面：深蓝面板、青蓝高亮、网格背景、状态指示与移动端布局。

## AI 操作提议格式

```xml
<SF_ACTION>
{"type":"task_create","title":"找到旅店","description":"在天黑前找到落脚处","reward":{"currency":30,"attributePoints":1}}
</SF_ACTION>
```

支持 task_create、task_progress、task_complete、event_notice、unlock_shop。每次最多一个操作提议，必须在面板中确认。任务完成操作要求进度达到 100%。

## 尚未实现 / 注意事项

- 这是可运行原型，不是正式稳定版；请先在测试聊天中验证。
- SillyTavern 的扩展事件数据结构可能随版本变化。若 AI 提议没有自动出现，请提供酒馆版本和控制台报错以便继续适配。
- 商品效果、BUFF 持续时间、库存系统、套装、跨系统联动、完整回滚和导入导出尚未实现。
- 数据写入当前聊天的 chatMetadata.system_flow_v1。删除聊天或清理聊天元数据可能导致对应存档丢失，重要进度请定期备份聊天。
